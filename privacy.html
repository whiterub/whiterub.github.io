개인정보처리방침

autoblog-backup · 시행일 2026-10-15

1. 누가 쓰는가

autoblog-backup은 소유자 한 사람이 자기 데이터를 백업하려고 쓰는 개인용 도구입니다. 다른 사용자에게 제공하지 않습니다.

2. 접근하는 Google 사용자 데이터

Google Drive 권한 중 https://www.googleapis.com/auth/drive.file 하나만 요청합니다. 이 권한으로는 이 도구가 만든 백업 파일만 만들고, 읽고, 지울 수 있습니다. 소유자의 다른 Drive 파일, 메일, 연락처 같은 다른 데이터에는 접근하지 않습니다.

3. 쓰는 목적

소유자 PC의 백업을 저장하고, 백업이 온전한지 확인하고, 필요할 때 복원하는 데만 씁니다.

4. 저장과 보호

  • 백업 내용은 소유자 PC에서 AES-256으로 암호화된 뒤 소유자의 Google Drive에 저장됩니다.
  • Google 로그인 정보(OAuth 토큰)는 소유자 PC에만 저장됩니다. 개발자가 운영하는 서버는 없습니다.

5. 공유

Google에서 받은 데이터를 누구에게도 팔거나 넘기지 않습니다. 광고나 분석 도구를 쓰지 않습니다.

6. 보관과 삭제

소유자가 Google Drive에서 백업 폴더를 지우면 데이터가 삭제됩니다. 이 도구의 접근 권한은 Google 계정 → 타사 앱 액세스에서 언제든 끊을 수 있습니다.

7. Google API 서비스 사용자 데이터 정책

autoblog-backup이 Google API에서 받은 정보를 쓰고 다른 앱으로 옮길 때는 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

8. 변경

이 방침이 바뀌면 이 페이지에 바뀐 날짜와 함께 알립니다.

Privacy Policy

autoblog-backup · Effective 2026-10-15

  1. Who uses it. autoblog-backup is a personal tool used only by its owner to back up the owner's own data. It is not offered to other users.
  2. Google user data accessed. It requests a single Google Drive scope, https://www.googleapis.com/auth/drive.file, which only allows creating, reading, and deleting the backup files this tool created. It does not access any other Drive files, mail, contacts, or other data.
  3. Purpose. The data is used only to store, verify, and restore backups of the owner's PC.
  4. Storage and protection. Backup contents are encrypted with AES-256 on the owner's PC before being stored in the owner's Google Drive. OAuth tokens are stored only on the owner's PC. There is no developer-operated server.
  5. Sharing. Data received from Google is never sold or transferred to anyone. No advertising or analytics tools are used.
  6. Retention and deletion. Deleting the backup folder in Google Drive deletes the data. Access can be revoked at any time at Google Account → Third-party access.
  7. Google API Services User Data Policy. autoblog-backup's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  8. Changes. Changes to this policy will be posted on this page with the date.
